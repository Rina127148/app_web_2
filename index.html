Отчёт по лабораторной работе №2

HTTP-запросы (7 заданий)

1) GET главная страница (HTTP/1.0)

curl -v http://kubsu-dev.ru/

2) GET внутренняя страница (HTTP/1.1)

curl -v http://kubsu-dev.ru/index.php

3) Определить размер file.tar.gz (HEAD)

curl -vI http://kubsu-dev.ru/file.tar.gz

4) Определить медиатип /image.png

curl -vI http://kubsu-dev.ru/image.png

5) Отправить комментарий POST

curl -v -X POST -d "comment=Мой комментарий" -H "Content-Type: application/x-www-form-urlencoded" http://kubsu-dev.ru/index.php

6) Получить первые 100 байт file.tar.gz

curl -v -r 0-99 http://kubsu-dev.ru/file.tar.gz

7) Определить кодировку /index.php

curl -vI http://kubsu-dev.ru/index.php
